
Este proyecto recrea la primera parte de la creación de un juego de mesa en formato digital.  

Participé en su desarrollo colaborando en:
- Implementación del **frontend** y**backend** la **lógica de pre-game**, incluyendo creación de jugadores, partidas, y algunas funcionalidades del juego. 
- Desarrollo de **API endpoints** con Python y FastAPI para las acciones del juego.  
- Integración con el **frontend en React**, creando componentes interactivos y gestión del estado de las partidas.  
- Pruebas unitarias y scripts de automatización para garantizar la correcta funcionalidad del juego.

El proyecto me permitió aplicar conocimientos en **programación orientada a objetos**, **desarrollo web** y trabajo en equipo en un entorno de colaboración bajo metodología agil scrum.
